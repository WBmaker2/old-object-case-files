# 오래된 물건 사건파일 기능·디자인 개선 계획

- 작성일: 2026-07-17
- 대상: 초등 5~6학년 학생용 공개 웹앱
- 기준 버전: 1.0.0
- 목표 버전: 1.1.0

## 점검 범위

공개 사이트에서 시작 화면 → 탐구 방법 → 사건 1 사진 관찰 → 가설 1 기록 → 목록 단서 공개 흐름을 직접 실행했습니다. 1280px 데스크톱, 375px 모바일, 320px 좁은 화면에서 화면 배치와 상호작용을 확인했고, 브라우저 경고·오류도 함께 점검했습니다.

## 발견한 개선점

### P0 · 선택하지 않은 가설도 기록 버튼을 누를 수 있음

가설 1을 고르지 않은 상태에서도 `가설 1 기록하기` 버튼이 활성화되어 있습니다. 누르면 화면 위쪽에 `등록되지 않은 가설입니다.`라는 개발자 관점의 오류 문구가 나타나 학생이 무엇을 해야 하는지 바로 알기 어렵습니다. 가설 수정 단계도 근거를 고르지 않은 채 제출할 수 있어 같은 종류의 오류가 뒤늦게 나타납니다.

### P0 · 활동 중 제목 버튼을 누르면 기록이 즉시 초기화됨

상단의 앱 제목은 언제든 시작 화면으로 돌아가는 버튼이지만, 진행 중 눌러도 확인 절차 없이 모든 기록이 사라집니다. 긴 3개 사건 활동에서는 실수로 누른 한 번의 클릭이 큰 손실이 됩니다.

### P1 · 전체 활동과 현재 단계의 위치가 보이지 않음

사건 번호는 사건 소개 화면에서만 보이고, 사진 관찰·가설 수정 화면에서는 전체 3개 사건 중 어디인지와 현재 사건의 어느 단계인지 확인하기 어렵습니다. 학생과 교사가 남은 활동량을 가늠할 수 있는 지속적인 진행 안내가 필요합니다.

### P1 · 긴 관찰 화면에서 다음 행동이 늦게 보임

유물 사진 높이가 화면의 절반 이상을 차지해 특징 선택과 다음 버튼이 첫 화면 아래로 밀립니다. 사진은 충분히 크게 유지하되, 과제 문장과 선택 영역이 더 빨리 이어지도록 이미지 높이와 간격을 조정할 필요가 있습니다.

### P1 · 선택 상태와 모바일 조작 영역이 약함

체크·라디오 선택 후 작은 기본 입력 표시만 바뀌어 선택 결과를 한눈에 확인하기 어렵습니다. 상단 도움말 버튼도 모바일에서 최소 터치 영역이 작습니다. 선택 카드의 배경·테두리 피드백과 44px 수준의 조작 영역을 적용합니다.

### P2 · 업데이트 내역이 한 줄 문장만 제공됨

현재는 최초 구현 한 줄만 있어 개선 이력을 빠르게 훑기 어렵습니다. 최신 개선을 위에 두는 목록 구조로 바꾸고 1.1.0 내용을 기록합니다.

## 구현 계획

1. 앱 상단에 `준비 → 사건 1 → 사건 2 → 사건 3 → 비교 → 기록표` 진행 안내를 추가하고, 사건 화면에는 `사진 관찰 → 가설 1 → 목록 단서 → 가설 2 → 맥락 단서 → 가설 3 → 사건 정리` 현재 단계를 표시합니다.
2. 가설 1은 하나를 고르기 전까지, 가설 2·3은 공개 단서를 하나 이상 고르기 전까지 기록 버튼을 비활성화하고 가까운 위치에 다음 행동 안내를 표시합니다.
3. 진행 중 앱 제목을 누르면 기록 삭제 확인 대화상자를 열어 실수로 초기화되지 않게 합니다.
4. 유물 사진의 최대 높이와 단계 간 여백을 줄여 선택 영역을 더 빨리 노출합니다.
5. 선택된 항목의 테두리·배경 피드백, 도움말 버튼의 최소 터치 높이, 모바일 버튼 너비를 개선합니다.
6. 앱 버전과 업데이트 내역을 1.1.0으로 갱신합니다.

## 완료 기준

- 가설 또는 필수 근거를 고르지 않으면 기록 버튼이 비활성화됩니다.
- 진행 중 제목을 눌러도 확인 전에는 기록이 지워지지 않습니다.
- 모든 핵심 화면에서 전체 사건 위치와 현재 사건 단계가 읽힙니다.
- 320px에서 가로 스크롤 없이 상단 도움말과 주요 버튼을 사용할 수 있습니다.
- 선택 상태가 색상만이 아니라 테두리와 입력 상태로도 구분됩니다.
- 업데이트 내역에 1.1.0 개선 내용이 표시됩니다.
- 기존 전체 완주 테스트, 콘텐츠 감사, 코드 크기 감사, 린트, 배포 빌드가 모두 통과합니다.
- 로컬 및 공개 사이트에서 시작 → 사건 1 관찰 → 가설 기록 흐름과 대화상자를 다시 확인합니다.

## 구현 결과

- 전체 6단계 진행 안내와 사건별 7단계 진행 안내를 추가했습니다. 좁은 화면에서도 `현재 단계 n/7 · 단계명`이 항상 보입니다.
- 가설 1은 가설 선택 전, 가설 2·3은 공개 단서 선택 전까지 기록 버튼이 비활성화됩니다.
- 진행 중 앱 제목을 누르면 기록 삭제 확인 대화상자가 열리며, 취소하면 현재 단계와 기록이 유지됩니다.
- 유물 사진 높이와 단계 간격을 줄이고, 선택 항목의 배경·테두리 피드백과 최소 44px 조작 영역을 적용했습니다.
- 320px 전체 진행 글자와 버튼 배치를 보완하고, 현재 단계를 완료 단계와 시각적으로 구분했습니다.
- 앱 및 업데이트 내역을 1.1.0으로 갱신했습니다.
