# 학습용 이미지 생성·교체 계획

## 목표

현재 앱에 포함된 유물 3개 이미지를 이미지 생성 모델로 새로 제작하고, 학생이 사진에서 관찰해야 하는 핵심 모양은 유지한 학습용 재구성 이미지로 교체한다.

## 분석 결과

- 대상 자산은 `public/assets/artifacts/`의 JPEG 3개다.
- 사용처는 `app/content/caseBank.ts`의 `assetManifest`와 `app/components/CasePanel.tsx`의 관찰 화면이다.
- 학습 목표는 유물 이름 맞히기가 아니라 사진에서 보이는 사실과 박물관 기록·해석을 구분하는 것이다.
- 따라서 생성 이미지에는 시대·용도·정답을 미리 알려 주는 글자나 장식물을 넣지 않는다.

## 생성 원칙

1. 유물의 관찰 가능한 형태를 중심으로 만든다.
2. 이미지 안에 글자, 로고, 워터마크, 박물관 마크를 넣지 않는다.
3. 실제 박물관 사진처럼 오해하지 않도록 앱의 출처 안내에서 `AI 생성 학습용 재구성 이미지`라고 명시한다.
4. 학생이 관찰 선택지와 연결할 수 있도록 밝고 단순한 배경, 한 물체 중심 구도를 사용한다.
5. 생성 이미지가 역사적 사실을 새로 증명하지 않는다는 범위 안내를 유지한다.

## 대상별 프롬프트 방향

| 대상 | 반드시 보일 형태 | 사용 맥락 |
| --- | --- | --- |
| 주먹도끼 | 한쪽 끝이 뾰족하고 반대쪽이 넓고 뭉툭함, 여러 면과 떼어 낸 흔적 | 사진 관찰에서 모양·표면 고르기 |
| 토우장식 뚜껑 | 둥근 흙빛 뚜껑, 뱀이 작은 개구리를 문 동물 장식, 눈·발가락·등 선 | 동물 장식과 작은 표현 관찰 |
| 청자 상감 주사위 | 작은 푸른빛 정육면체, 여러 면의 점 표시, 매끈한 청자 표면 | 정육면체·점·표면 관찰 |

## 구현·검증 순서

1. 이미지 생성 모델로 대상별 PNG를 각각 생성한다.
2. 생성 결과를 눈으로 검토해 형태·구도·금지 요소를 확인한다.
3. `public/assets/artifacts/`에 새 파일을 추가하고 `assetManifest` 경로·출처 메타데이터를 학습용 재구성 이미지에 맞게 갱신한다.
4. 관찰 화면의 캡션과 자료·이미지 출처 대화상자에 AI 생성 이미지임을 표시한다.
5. 단위 테스트·콘텐츠 감사·빌드로 이미지 경로와 설명의 일관성을 확인한다.
6. 변경 내역에 2026-08-15 교체 내용을 기록한다.

## 완료 기준

- 세 대상 모두 새 생성 이미지가 실제 화면에 표시된다.
- 기존 관찰 선택지와 대체텍스트가 이미지의 보이는 특징과 일치한다.
- 이미지 안에 글자·워터마크가 없다.
- 앱이 생성 이미지를 박물관 공식 사진으로 오해하게 만들지 않는다.
- 테스트와 빌드가 통과한다.

## 구현 결과 (2026-08-15)

- 세 이미지를 `public/assets/artifacts/generated/`에 생성·삽입했다.
- `assetManifest`와 사진 캡션·출처 대화상자를 생성 이미지 기준으로 갱신했다.
- 화면에 실제 박물관 사진이 아니라는 안내와 참고 공식 기록 링크를 표시했다.
- 앱 버전을 `1.3.0`으로 올리고 업데이트 내역에 교체 내용을 추가했다.
- `npm test`, `npm run lint` 통과를 확인했다.
