# 오래된 물건 사건파일 — 초등학생 실사용 개선 계획

- 작성일: 2026-07-18
- 대상: 초등학교 5~6학년 학생
- 기준 배포본: v1.1.0 (`https://old-object-case-files.wbmaker.chatgpt.site/`)
- 테스트 화면: 데스크톱, 모바일 375 × 812
- 테스트 흐름: 시작 → 탐구 방법 → 사건 1·2·3의 7단계 활동 → 비교 → 최종 기록표

## 1. 실사용 테스트 결과

### 잘 작동한 점

- 사진 관찰에서 정확히 두 항목을 고르게 하고, 선택이 끝나기 전에는 다음 버튼을 비활성화해 실수를 막는다.
- 모든 주요 버튼의 높이가 44px 이상이라 모바일 터치가 어렵지 않다.
- 생각을 바꾸어도 실패가 아니라는 안내와 개인정보를 쓰지 않는 구조가 초등 수업에 안전하다.
- 실제 박물관 사진, 출처, 공식 기록 링크가 모든 사건에서 분명하게 연결된다.
- 공개 화면의 브라우저 콘솔 오류는 없었다.

### 개선이 필요한 점

1. **학생에게 어려운 전문어가 설명 없이 반복된다.**
   - `가설`, `설명력이 있다`, `목록 단서`, `맥락 단서`, `출토 맥락`, `비교 자료`, `인양`, `판단 보류`가 활동 전반에 반복된다.
   - 첫 화면에서도 `추론`, `가설`을 알아야 활동 목적을 이해할 수 있다.

2. **문장이 길거나 어색한 곳이 있다.**
   - `가설 2을 기록했어요`는 `가설 2를 기록했어요`로 고쳐야 한다.
   - `수를 우연히 정하는 놀이 도구`, `다시 살아남·이어짐`은 초등학생이 자연스럽게 이해하기 어렵다.
   - `현재 사진으로 가장 설명력이 있다고 생각하는 가설`은 질문 자체를 읽는 데 부담이 크다.

3. **교사용 정보가 학생의 첫 진입을 방해한다.**
   - 사건 소개의 `[6사04-01]`, `[6사04-02]`, `[6사04-03]`은 학생에게 의미가 없고 활동 안내처럼 보인다.

4. **모바일 진행 표시가 너무 촘촘하다.**
   - 사건 안의 7개 단계가 가로 스크롤 한 줄에 모두 나타나 현재 할 일보다 전체 용어가 먼저 보인다.
   - 작은 화면에서는 뒤 단계가 잘려 보여 활동이 복잡하다는 인상을 준다.

5. **완료 화면과 사건 정리가 지나치게 길다.**
   - 375px 화면에서 최종 기록표 높이가 약 2,924px이며, 세 사건의 모든 가설과 근거가 한꺼번에 펼쳐진다.
   - 사건 정리에서도 이미 본 `가설 변화 기록` 전체가 다시 펼쳐져 다음 사건으로 넘어가는 버튼을 찾기 어렵다.

6. **활동 분량을 시작 전에 알 수 없다.**
   - 사건이 3개라는 것은 진행 표시로 추측할 수 있지만 예상 시간과 반복 구조는 첫 화면에 안내되지 않는다.

## 2. 개선 원칙

- 교과 개념은 없애지 않고, 학생말을 먼저 보여 준 뒤 필요한 경우 괄호로 교과 용어를 덧붙인다.
- 매 화면에서 학생이 지금 해야 하는 행동을 한 문장으로 분명히 제시한다.
- 긴 기록은 기본적으로 접고, 학생이 원할 때 펼쳐 보게 한다.
- 박물관의 사실 기록과 앱의 해석 구분은 그대로 유지한다.
- 이미지와 자료의 출처·권리 표시는 변경하지 않는다.

## 3. 구현 범위

### 문장과 용어

- 첫 화면에 `약 10~15분 · 사건 3개` 안내를 추가한다.
- `가설`을 처음 등장할 때 `가설(단서를 보고 세운 지금의 생각)`으로 풀어 쓴다.
- 진행 단계는 `사진 보기 → 첫 생각 → 박물관 기록 → 생각 고치기 → 새 비교 단서 → 마지막 생각 → 정리`로 바꾼다.
- `설명력이 있다고 생각하는 가설`은 `사진과 가장 잘 맞는 생각`으로 바꾼다.
- `판단 보류`는 `아직 결정하지 않기`를 먼저 보여 주고 교과 용어를 보조로 둔다.
- `출토`, `인양`, `변태·탈피·재생`처럼 필요한 역사·과학 용어는 같은 문장에서 쉬운 말로 풀어 쓴다.
- `가설 2을` 조사 오류와 사건별 어색한 가설 문장을 고친다.

### 기능과 UI

- 사건 진행 표시를 진행 막대와 `지금 할 일` 중심으로 단순화한다. 전체 7단계 목록은 작은 화면에서 숨기거나 접는다.
- 사건 중간과 정리 화면의 `가설 변화 기록`을 접고 펼칠 수 있는 영역으로 바꾼다.
- 최종 기록표는 사건별로 접힌 카드 3개를 제공하고, 학생이 하나씩 펼쳐 확인하게 한다.
- 사건 소개의 교육과정 코드는 학생말로 바꾸고, 정확한 코드는 보조 설명으로만 제공한다.
- 시작·비교·결과 버튼을 학생 행동 중심 문장으로 바꾼다.
- 업데이트 내역에 v1.2.0과 2026-07-18 개선 내용을 추가한다.

## 4. 완료 조건

- 375 × 812와 320px 폭에서 문서 전체 가로 넘침이 없다.
- 사건 진행 영역에서 현재 단계와 지금 할 일이 첫 화면 안에서 읽힌다.
- 학생이 전문어 설명 없이도 다음 행동을 이해할 수 있다.
- `가설 2을` 문구가 어디에도 남지 않는다.
- 최종 기록표의 기본 화면 높이가 기존 2,924px보다 뚜렷하게 줄어든다.
- 키보드만으로 시작, 선택, 기록, 접기·펼치기, 다시 시작을 사용할 수 있다.
- 기존 박물관 링크, 이미지 출처, 근거 상태, 선택 검증, 다시 시작 확인 기능이 유지된다.
- 단위·컴포넌트 테스트, 빌드, 린트, 공개 사이트 모바일 실사용 검증을 통과한다.

## 5. 구현 후 기록

구현과 검증이 끝나면 변경 파일, 자동 테스트 결과, 모바일 실사용 결과, 공개 배포 버전을 이 문서에 추가한다.

### 구현 완료 · 2026-07-18

- 시작 화면에 `약 10~15분 · 사건 3개`와 가설의 쉬운 뜻을 추가했다.
- 현재 사건 화면은 `지금 할 일`을 먼저 보여 주고, 7단계 목록은 작은 화면에서 숨겼다.
- 사건 안의 생각 기록과 최종 기록표의 사건별 기록은 기본으로 접혀 있으며, 키보드와 마우스·터치로 펼칠 수 있다.
- 교육과정 코드는 `선생님 참고` 안의 보조 정보로 옮기고, 학생에게는 이번 활동에서 해 볼 일을 먼저 보인다.
- 어려운 말은 쉬운 말 뒤에 괄호로 보충했고, `가설 2을` 문구는 `생각 2를`로 고쳤다.
- 자동 검증: `npm test`(21개 단위 테스트, 서버 렌더, 콘텐츠·코드 크기 감사), `npm run lint`, `npm run build` 통과.
- 로컬 구현 버전은 `1.2.0`이며, 이 시점에는 커밋·푸시·공개 배포를 하지 않았다.

### 구현 후 실사용 검증 · 2026-07-18

- 모바일 375 × 812에서 세 사건을 처음부터 최종 기록표까지 다시 완주했다.
- 사건 화면은 `지금 할 일`, 1~7단계 진행 막대, 학생말 단계명을 표시하며 전체 7단계 목록은 작은 화면에서 숨긴다.
- 최종 기록표의 기본 높이는 약 2,924px에서 1,073px로 줄었고, 세 사건 기록은 모두 접힌 상태에서 사건명을 보여 준다.
- 접기·펼치기는 표준 버튼과 `aria-expanded`·`aria-controls`를 사용하며, user-event 키보드 테스트에서 Enter와 Space 동작을 확인했다.
- 320px 화면에서 `clientWidth`와 `scrollWidth`가 모두 305px로 측정되어 가로 넘침과 수평 스크롤이 없음을 확인했다.
- 업데이트 내역에서 `2026-07-18 / 1.2.0` 항목을 확인했다.
- 최종 자동 검증: Vitest 22개, 서버 렌더 테스트, 빌드, 콘텐츠·코드 크기 감사, ESLint, diff 검사를 모두 통과했다.
- 독립 코드 리뷰에서 Critical·Important 항목이 없고 배포 준비 완료 판정을 받았다.
