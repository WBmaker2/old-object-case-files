# 유물·주장 검토 기록

검토일: 2026-08-15
승인 기록: 세 유물의 공식 기록을 참고해 이미지 생성 모델로 학습용 재구성 이미지를 만들었습니다. 생성 이미지는 실제 박물관 사진이 아니며, 학생이 관찰할 형태를 위한 수업용 시각 자료입니다. 공식 기록은 역사적 맥락을 확인하는 참고 자료로만 연결합니다.

## 사건 1 · 주먹도끼

- 소장품: 국립중앙박물관 `주먹도끼`, `신수18710`, 소장품 ID 5200
- 공식 기록: [소장품 페이지](https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?schM=view&searchId=search&relicId=5200)
- 확인 범위: 구석기, 화강암, 16.5 × 12.0 × 7.4cm, 연천군 출토
- 학생용 관찰: 한쪽의 뾰족한 끝, 반대쪽의 상대적으로 뭉툭한 부분, 떼어 낸 듯한 면
- 해석의 한계: 국립중앙박물관의 여러 용도 도구 설명은 현재 근거에 따른 설명이며, 이 한 점의 정확한 사용 대상·날짜·횟수는 알 수 없습니다.

## 사건 2 · 토우장식 뚜껑

- 소장품: 국립경주박물관 `토우장식 뚜껑`, `경주5772`
- 공식 기록: [소장품 페이지](https://gyeongju.museum.go.kr/kor/html/sub04/0406.html?GotoPage=2&dvs_code=&mng_no=424&mode=V)
- 확인 범위: 신라 4~6세기, 경주 월성로 무덤군 돌덧널무덤 출토, 뱀·개구리 표현
- 학생용 관찰: 개구리를 문 뱀과 눈·발가락·등의 선
- 해석의 한계: 재생을 느꼈을 가능성은 박물관이 제시한 역사적 해석입니다. 제작자의 정확한 마음이나 신라 전체의 생각으로 확정하지 않습니다.

## 사건 3 · 청자 상감 주사위

- 소장품: 국립중앙박물관 `청자 상감 주사위`, `덕수6421`, 소장품 ID 1495
- 공식 기록: [소장품 페이지](https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?relicId=1495&schM=view&searchId=search)
- 확인 범위: 고려, 청자, 약 1.2cm 정육면체, 출토지 불명, 박물관의 놀이·여가 분류
- 학생용 관찰: 작은 정육면체와 여러 면의 점 표시
- 해석의 한계: 놀이 도구일 가능성은 목록 분류와 비교 자료가 뒷받침하지만, 사용자·놀이 규칙·이 소장품의 정확한 출토지는 알 수 없습니다.

## 표현 검수 기준

- `사진에서 보여요`는 사진에서 바로 확인 가능한 모양으로만 썼습니다.
- `박물관 기록이에요`는 소장품 목록의 시대·재질·크기·출토지·분류만 썼습니다.
- `근거로 이렇게 추론해요`는 가능성·박물관 해석임을 유지했습니다.
- `아직 알 수 없어요`에는 소유자, 정확한 쓰임, 제작자의 직접 의도, 놀이 규칙처럼 자료가 말하지 않는 내용을 남겼습니다.
- 한 유물에서 한 시대의 모든 사람을 일반화하지 않았습니다.
