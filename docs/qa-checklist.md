# MVP QA 체크리스트

검토일: 2026-07-17

## 자동 검증 완료

- [x] 정확히 3개의 사건, 판단 보류, 미확인 단서, 단계별 단서가 콘텐츠 검증을 통과합니다.
- [x] 사진 관찰은 정확히 2개여야 첫 가설을 만듭니다.
- [x] 공개 전 단서는 근거로 저장할 수 없습니다.
- [x] 유지·바꾸기·다듬기·판단 보류의 가설 전이 규칙과 불변 버전 기록을 검증합니다.
- [x] 출처/업데이트 대화상자, 네 정보 상태 라벨, 이전 가설 보존을 컴포넌트 테스트로 검증합니다.
- [x] 원격 런타임 이미지, 허용 밖 라이선스, 누락된 해시·처리 내역, 저장·업로드·경쟁 언어를 정적 감사로 차단합니다.
- [x] 코드 파일이 500줄 미만인지 검사합니다.
- [x] 정적 빌드와 서버 렌더 시작 화면 검증을 실행합니다.

## 구현으로 확인한 접근성 조건

- [x] 네이티브 `fieldset`, `legend`, 라디오, 체크박스를 사용합니다.
- [x] 키보드 초점 표시, `aria-live` 상태, 새 단서 제목으로의 초점 이동을 제공합니다.
- [x] 출처·업데이트 대화상자는 Esc/닫기와 원래 버튼으로의 초점 복귀를 제공합니다.
- [x] `prefers-reduced-motion`, forced colors, 320px 단일 열 CSS 규칙을 포함합니다.
- [x] 사진 대체텍스트에 시대·용도 답을 미리 넣지 않습니다.

## 남은 수동 확인

- [ ] 실제 브라우저에서 320px·375px·768px·1280px 및 200% 확대를 확인합니다.
- [ ] 키보드만으로 세 사건 전체를 완주하고 대화상자 탭 순서를 확인합니다.
- [ ] 실제 사진의 작은 세부가 학생용 관찰 문장과 충분히 일치하는지 역사·권리 담당자가 최종 확인합니다.
- [ ] 스크린리더로 단서 공개 직후 읽기 순서와 출처 링크 문구를 확인합니다.

이 작업에서는 요청에 따라 브라우저 UI QA·배포·커밋·푸시를 수행하지 않았습니다.
